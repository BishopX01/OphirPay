# OphirPay Security Policy
#
# This file provides security researchers with information about how to
# report vulnerabilities in OphirPay (RFC 9116).
#
# The GitHub private-advisory form is the only reliable channel: it does not
# depend on mail deliverability. The previously listed
# `security@ophirpay.com` mailbox has no MX record and bounces (issue #1280),
# and `security@ophirpay.dev` does not resolve yet, so no `mailto:` contact is
# advertised. If the "Report a vulnerability" button is unavailable, open a
# public issue with no vulnerability details and ask a maintainer to open a
# private advisory (see the Policy link).
#
# For more details, see: https://github.com/OphirPay/OphirPay/blob/main/SECURITY.md
#
